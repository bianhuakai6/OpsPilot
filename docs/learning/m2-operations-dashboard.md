# M2 第一版运维控制台

## 页面入口

启动服务后访问：

```text
http://127.0.0.1:8000/dashboard
```

`/docs` 仍然是接口调试页；`/dashboard` 才是面向运维使用者的第一版界面。

## 页面展示的数据

- 进程存活：调用 `/healthz`；
- 服务就绪：调用 `/readyz`；
- MySQL 和 Redis：读取巡检接口中的依赖检查结果；
- 在线资源：调用活动查询接口展示容量；
- 最近一次巡检：调用 `POST /api/v1/inspections/run` 展示证据和建议。

页面没有写死“正常”，每次加载和点击“重新巡检”都会重新请求后端。因此停掉 MySQL/Redis 或让服务异常时，界面会显示对应风险。

## 当前边界

这是第一版只读控制台，暂不提供发布、回滚、自动修复和权限管理。它的价值是让后端健康状态、依赖状态、业务容量和巡检证据有一个可直接验收的统一入口。后续会增加指标摘要、巡检历史、告警状态和 Agent 建议。
