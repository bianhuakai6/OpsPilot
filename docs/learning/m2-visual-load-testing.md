# M2 可视化压力测试

## 页面和导航

- 服务概览：`http://127.0.0.1:8000/dashboard`
- 压力测试：`http://127.0.0.1:8000/load-test`

两个页面顶部都可互相跳转。压力测试页选择预设只读目标、持续时间和并发数，开始后每 500 毫秒查询任务状态，显示请求总数、失败率、吞吐量、P50/P95 和最近延迟曲线。

## 安全边界

后端只接受 `health`、`readiness`、`activity` 三个固定目标，并将其映射为本机 GET 路径。客户端不能提交 URL、HTTP 方法或请求体。后端同时校验持续时间 1-30 秒、并发 1-8，每次任务最多发送 100,000 次请求；同一时刻只允许一个活动任务。通常测试会运行到所选时长；如果极快的目标提前达到请求安全上限，结果会显示“已达到请求安全上限”。

压测请求会继续进入请求计数和延迟指标，但请求头会标记为内部压测流量，应用中间件不逐条记录它们。Uvicorn 的逐请求 access log 也已关闭，普通 API 请求仍由应用结构化日志记录。浏览器每 500ms 查询一次任务进度，因此一次 30 秒实验只会增加约 60 次状态查询日志，而不是为每个负载请求写日志。

停止操作会阻止继续派发请求，并等待已经发出的请求收尾，然后保留最终结果。任务状态和报告目前只保存在应用内存，应用重启后清空；暂未写入数据库，也没有下载报告功能。

## 代码职责

- `app/load_testing.py`：白名单、边界、后台任务、状态聚合和停止逻辑。
- `app/routes/load_testing.py`：开始、查询当前任务、停止三个 API。
- `app/static/load-test.html`：参数表单、轮询、指标和延迟曲线。
- `app/static/dashboard.html`：进入压力测试的导航链接。

运行后可用浏览器检查开始/停止交互。也可以通过 `/docs` 查看 `POST /api/v1/load-tests`、`GET /api/v1/load-tests/current` 和 `POST /api/v1/load-tests/stop` 的接口契约。
